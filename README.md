# Plataforma de divulgação e reserva de alimentos excedentes em Itapetinga–BA

Projeto Integrador do curso de Tecnologia em Análise e Desenvolvimento de Sistemas da Universidade Estadual do Sudoeste da Bahia (UESB).

## Objetivo geral

Desenvolver uma plataforma web responsiva para apoiar a divulgação e a reserva de alimentos excedentes entre estabelecimentos doadores e instituições sociais cadastradas em Itapetinga–BA, permitindo o acompanhamento das ofertas, das reservas e dos registros de retirada.

## Stack definida

- Back-end: Java 21 e Spring Boot 3.4.
- Banco de dados: PostgreSQL 16.
- Front-end: HTML5, CSS3 e JavaScript (ES6+).
- Integração: API REST com dados em JSON, consumida pela interface por meio da Fetch API.
- Implantação inicial prevista: interface estática e API disponibilizadas pela mesma aplicação Spring Boot.
